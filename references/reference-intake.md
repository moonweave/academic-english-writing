# Learning from reference papers

Persist analytical guidance, not a claim that model weights changed. The quality target is the user's preferred writing, not journal prestige or citation count.

## Select and inspect

Use user-selected papers first. If asked to find examples, explain selection criteria: a clear question, traceable claims, coherent paragraphs, and precise treatment of evidence. Label agent-selected examples provisional until endorsed. A paper can contain a useful pattern and awkward sentences elsewhere.

Verify title, authors, year, DOI or stable URL, and actual access scope. Prefer legally available primary-source text or user-provided manuscripts. Do not bypass restrictions. An abstract supports abstract-level analysis only; an indexed excerpt supports that excerpt only. For PDFs, identify page and section and check extraction against the document when unreliable.

Read paragraphs in context; fragments cannot establish a whole paragraph's function. Keep unpublished text local unless the user authorizes sending it elsewhere. Do not automatically scan research folders, mutate a manuscript, or duplicate a whole paper into the skill.

## Create an analytical entry

Record in prose, using the existing library format:

- Source identity and stable link; inspection date; access scope; user-selected or provisional.
- Location: section, paragraph opening or short locator, and page/figure where available.
- Rhetorical problem and why the passage solves it.
- Abstract structure: information order, clause relationship, grammatical choices, and their function.
- Preconditions: evidence or context needed before the pattern is valid.
- Failure modes: overclaiming, confused scope, or repetition.
- A short, accurately checked source excerpt that includes the grammatical unit being analyzed; obey quotation limits across the entire source. A noun-phrase anchor alone cannot demonstrate a passive clause. When a quotation covers only part of the relationship, say exactly which part.
- A labeled editorial schematic identifying the subject, predicate and relevant clause/complement relationship. Abstract the grammar rather than reconstructing the source’s distinctive wording; do not present a paraphrased schematic as a quotation.
- An original application on different content, explicitly marked invented. Explain the subject/verb, clause relation, tense or focus choice it demonstrates; do not merely label it “clear” or “concise”.

Separate source observations from interpretation. Prefer paraphrased analysis. Attribute indispensable short quotes and respect applicable limits; do not reconstruct long passages through multiple short quotes. Do not copy distinctive wording and substitute technical nouns. Grammar and rhetorical organization are reusable; scientific claims still need appropriate scientific citations.

## Store and retrieve

Before storing an entry, check that its analysis can guide an actual new sentence, its example obeys its stated preconditions, and it adds a useful decision beyond an existing entry. If the source cannot be inspected, mark the limitation rather than inventing a fragment.

When expansion is requested, add entries to the domain files linked from `paper-patterns.md`; add a new file only when an existing domain file becomes difficult to navigate. Link new files from an existing entrypoint. Deduplicate by DOI plus passage location. Persist user preferences only when actually expressed.

Index by domain, section, and rhetorical problem. Choose patterns matching the argument and evidence rather than generating a repeated template. State how many papers/passages were inspected and entries added. Restricted papers remain excluded from full-text-learning claims.
